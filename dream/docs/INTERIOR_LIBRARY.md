## 三层世界模型

| 层 | 含义 | 当前 Dream |
| --- | --- | --- |
| **1 室外地图** | 区域壳层、路网、建筑外观、门户 | Phase 1–4 进行中（村环 / 农田市集 / 林缘车站…） |
| **2 可进入空间** | 房屋/店/仓/站/灯塔等内部 | **C 类主战场**（本文件） |
| **3 功能/隐藏空间** | 矿洞、井底、密道、节日覆盖、水下等 | C + D/E/F/H 交叉 |

目标结构（开发顺序）：

```text
世界 → 区域(A) → 建筑外观(B) → 室内(C) → 地下(D) → 交互(G) → 玩法(E) → 剧情/节日(F) → 时空状态(H)
```

避免：「地图外面很好看，进门之后什么都没有。」

## 优先 10 类（Phase 5 Wave A）

室外壳层 DONE 后 **最先** 做这 10 包（详见 `PHASE5.md`）：

1. **住宅室内** — C01（升级档）+ C02（模板子集，禁止单模板）  
2. **商店室内** — C04 子集：杂货 / 铁匠 / 酒馆  
3. **农建内部** — C03：谷仓 / 鸡舍  
4. **市场摊位多状态** — C05 状态机  
5. **钓鱼完整最小闭环** — C18–C22  
6. **矿洞入口层** — C17  
7. **井底 / 地下** — C14 + C15  
8. **灯塔内部** — C12（依赖室外 A14）  
9. **森林隐藏** — C27 / C26（依赖 A05 / A07）  
10. **昼夜天气壳** — C56–C57 / H  

**禁止** Phase 5 一次做完 C01–C62 全表。

| 项 | 约定 |
| --- | --- |
| 场景路径 | `res://scenes/interiors/{c_id}/...` |

## 禁止偷懒

- 禁止只做门点击弹 InfoPanel、不进真实室内场景  
- 禁止所有村民住宅共用一个室内模板  
- 禁止市场摊位永远「满货营业」一种状态  
- 禁止水井/瀑布/山洞只有外观入口、无内部场景编号  
- 禁止未完成室外壳层就并行开工 C01–C62 全表  
- 禁止室内场景无返回室外的 portal / TopBar  
- 禁止把节日/夜市做成整盘新大地图而不复用广场骨架+装饰层（除非本文件标明例外）  
- 禁止 UI 把所有室内入口堆进一个弹层  
- 禁止复制室外 `*_assembler.gd` 只改类名交差室内
