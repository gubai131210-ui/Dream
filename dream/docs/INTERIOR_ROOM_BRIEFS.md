# Dream Phase 5 — 室内差异化设计简报（C01–C04）

**Status:** BRIEF — 指导 Wave A 二次打磨，不替代 `INTERIOR_FOUNDATION.md`  
**Date:** 2026-09-11  
**Refs:** Stardew / Harvest Moon cottage packs · Farming 101 barn/coop · MutterPixel General Store & Village Tavern · Seliel Thatch Roof Home hearth

目标：每间房在 **轮廓 / 分区 / 签名道具 / 动线 / FX** 上一眼可辨；色板对齐室外奶油墙 + 深木线脚（`building_00` 语言）。温馨 = 木材 + 地毯 + **局部** `PointLight2D`，禁止整屋橙洗。

---

## `c01_home` — 主角住宅

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | 最宽住宅：三区并列可读 — **壁炉起居（中北）+ 厨房（西/西北）+ 床区（东/东南）**。比村民宅更“满”但仍留中央通廊。建议显著大于 `c02_*`（例：~32×20）。 |
| **地板 / 墙 mood** | 暖木地板；奶油墙 + 深色护墙；北窗光柱。Seliel 式壁炉墙为视觉锚点（壁炉可带简易灶台感）。 |
| **必有签名道具** | 壁炉/炉台、厨柜台或灶、双人床、起居小桌+椅、入口地毯、少量盆栽。 |
| **动线 circulation** | 南门 → 中轴通廊 → 起居；厨房贴侧墙不挡门；床区最深、不与门口正对。 |
| **动态 FX** | 壁炉火光闪烁 + 窗光 shaft；灶台可有微弱暖点光。 |
| **防抄贴** | 禁止与 `c02_*` 同尺寸同道具清单；禁止只有床+箱无壁炉厨房分区。 |

## `c02_elder` — 老人宅

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | **最小、最空**村民宅；负空间即角色。单人尺度，角落茶区 + 远门床。建议最紧凑（例：~26–28×16–18）。 |
| **地板 / 墙 mood** | 略偏冷的奶油/灰奶油墙；木地板更素；灯光更柔、更少。 |
| **必有签名道具** | 茶几、单靠椅、药箱/药瓶架、单人床、一盏台灯；**少杂物**。 |
| **动线 circulation** | 南门 → 短直通廊 → 窗边茶区；床靠远墙，路径几乎无阻挡。 |
| **动态 FX** | 仅台灯/窗光；**无炉火**（安静宅）。 |
| **防抄贴** | 禁止堆粮袋/货箱/工具；禁止与农家同密度。 |

## `c02_farmer` — 农家宅

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | 门厅“工作前厅”+ 内侧粗简餐厅 + 后墙床。比老人宅更杂、比商贾宅更土。中等矩形（勿与 `c01` 同宽）。 |
| **地板 / 墙 mood** | 偏黄的暖木地板；奶油墙可略脏/磨损感；护墙深木。 |
| **必有签名道具** | **门边**工具架或锄镰箱、粮袋/种子袋、粗饭桌+凳、水桶、夫妻床。 |
| **动线 circulation** | 南门立刻经过工具/粮袋区再入餐厅；床在最深处。 |
| **动态 FX** | 壁灯暖黄即可；可选门口尘土微粒（弱），无锻造火。 |
| **防抄贴** | 工具/粮袋必须贴门区，禁止全塞东墙当“通用储物角”。 |

## `c02_merchant` — 商贾宅

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | **一半起居 / 一半仓储**：西账桌区 vs 东货箱堆。比农家“更整齐、更贵”。 |
| **地板 / 墙 mood** | 偏净的奶油墙；地板木色更均匀；**更好的地毯**（比农家更大或花纹更明显）。 |
| **必有签名道具** | 账桌+账本/算盘感道具、货箱垛、精品小箱、较新壁灯、床、**好看地毯**。 |
| **动线 circulation** | 南门 → 地毯起居轴 → 账桌；货箱半区不挡主轴，可侧绕。 |
| **动态 FX** | 账桌局部灯；无火无动物。 |
| **防抄贴** | 禁止做成迷你杂货店（无南向营业柜台）；仓储是“宅内半仓”，不是货架墙。 |

## `c02_blacksmith_home` — 铁匠宅（家，非铺）

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | 偏暗小宅：生活区 + **家用淬火/工具角**；**绝无北墙大锻炉**。比 `c04_smith` 更矮更窄、更像住人。 |
| **地板 / 墙 mood** | 墙/地板整体更暗（烟灰感）；木地板可带深渍；灯光偏橙但仍局部。 |
| **必有签名道具** | 厚桌、锤钳工具箱、**家用淬火桶**、少量铁件、床、壁灯。 |
| **动线 circulation** | 南门 → 起居；工具/淬火角贴侧墙，不占中心通廊。 |
| **动态 FX** | 壁灯偏暖；淬火角可有极弱蒸汽/水汽（可选）；**无锻炉火焰动画**。 |
| **防抄贴** | 禁止复制 `c04_smith`（无砧、无北锻炉、无顾客长椅）。 |

## `c03_barn` — 谷仓

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | **最大、横向**：中央过道 + **左右畜栏**（Farming 101）。明显宽于住宅与鸡舍（例：~34×22）。无床、无柜台。 |
| **地板 / 墙 mood** | 干草/土木地板（比住宅更糙）；深木板墙；少窗或高窗；无奶油客厅感。 |
| **必有签名道具** | 左右 stall **隔栏（rails）**、饲料槽/水槽、**干草垛**、**北端粮垛**、饲料袋、农具箱、吊灯。 |
| **动线 circulation** | 南门 → **正中纵/横过道**直通北端；畜栏只沿两侧，过道必须畅通。 |
| **动态 FX** | 吊灯光斑；干草尘微粒；**大型动物 idle/踱步**（至少示意）。 |
| **防抄贴** | 禁止塞满箱子当储藏室；无畜栏过道 = 不合格；**禁止无隔栏只靠干草暗示 stall**。 |

## `c03_coop` — 鸡舍

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | **最窄最短**室内；单通道贴墙巢箱。必须一眼比谷仓“小一号”（例：~20–22×14–16）。 |
| **地板 / 墙 mood** | 浅木屑/土色地板；木板墙；一扇小窗即可。 |
| **必有签名道具** | **低围栏笔（enclosure）**、墙边巢箱排、栖架 roost、鸡食袋、饮水槽、小灯。 |
| **动线 circulation** | 南门 → 窄中道入笔（南边 `gaps`）；巢箱贴一侧墙，栖架在对侧或北端，不可堵死。 |
| **动态 FX** | 鸡 pecking / 短距走动（**笔内**）；可选羽毛尘；弱暖灯。 |
| **防抄贴** | 禁止用谷仓缩小版；无巢箱+栖架+鸡 = 不合格；**禁止无围栏空地散鸡**。 |

## `c04_grocery` — 杂货店

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | MutterPixel 店型：**三面货架围合 + 南向柜台**（店主在北、顾客在南）。宽于鸡舍、接近中型住宅但分区是“店”不是“家”。 |
| **地板 / 墙 mood** | 干净木地板；奶油墙；货架高对比色罐瓶；比酒馆亮。 |
| **必有签名道具** | 高货架（墙）、南向柜台、收银/秤感、蔬果篮筐、米糖袋、告示板（可选）。 |
| **动线 circulation** | 南门 → 顾客区 → **柜台前停步**；店主区在柜台北，顾客不穿入。 |
| **动态 FX** | 店灯稳态暖光；可选架上玻璃高光，无炉火。 |
| **防抄贴** | 柜台必须南向营业轴；禁止床；禁止只有箱子无货架墙。 |

## `c04_smith` — 铁匠铺（营业）

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | 工坊： **北锻炉墙 + 中砧 + 南顾客通道/候坐**。比铁匠宅更“公开、更热、更石”。 |
| **地板 / 墙 mood** | **石地板**（或石+木混合）；深灰石/熏黑墙；整体比杂货暗。 |
| **必有签名道具** | 北墙锻炉、铁砧、淬火桶、成品/废料箱、**顾客长椅**、工具挂墙。 |
| **动线 circulation** | 南门 → 候坐区 → 观望线看向砧与炉；玩家不绕进炉后危险区。 |
| **动态 FX** | **锻炉火焰动画** + 强橙红局部光；可选火星/热浪；淬火蒸汽。 |
| **防抄贴** | 禁止与 `c02_blacksmith_home` 共用同一布局；无砧+北炉 = 不合格。 |

## `c04_tavern` — 酒馆

| 项 | 简报 |
| --- | --- |
| **轮廓 silhouette** | MutterPixel 酒馆： **西侧吧台+酒桶墙**，东/中餐桌群，北或东壁炉。比杂货更暗更“深木”。建议接近或略大于 `c01` 进深。 |
| **地板 / 墙 mood** | 深木地板；石木过渡墙；高对比暗木吧台；整体低照度。 |
| **必有签名道具** | 西吧台、横放酒桶 keg（`barrel_0` 特例）、酒杯架、圆桌/高凳、壁炉、告示板（可选）。 |
| **动线 circulation** | 南门 → 座席区；吧台贴西，顾客沿吧台前侧走动，不穿入桶后。 |
| **动态 FX** | **壁炉火** + 壁灯/火把闪烁；吧台灯带；可选杯盏反光。 |
| **防抄贴** | 禁止把 `barrel_0` 当通用立桶用到别的房；无西吧+火 = 不合格。 |

## 尺寸关系（防同框）

| 族 | 相对轮廓 | 禁止 |
| --- | --- | --- |
| 住宅 `c01` / `c02_*` | `c01` 最大最分区；`elder` 最小最空；其余中等但道具语义不同 | 家/店/仓同一 `room_w`/`room_h` |
| 农场 `c03_*` | `barn` 最宽有过道畜栏；`coop` 最窄 | 鸡舍=缩小谷仓 |
| 店铺 `c04_*` | 杂货=货架+南柜；铁匠=石地北炉；酒馆=西吧深木 | 三店同一柜台朝向/道具包 |

## 禁止偷懒

1. **禁止**全房共用「长椅 + 木箱」万能套件交差（每房必须有上表签名道具）。  
2. **禁止**住宅 / 店铺 / 谷仓（及鸡舍）使用相同 `room_w` / `room_h`。  
3. **禁止**该有火/炉/动物处缺动态 FX（壁炉、锻炉、酒馆火、谷仓动物、鸡舍 pecking）。  
4. **禁止**室内色板偏离室外奶油墙 + 深木线脚（禁止棋盘格地板、纯色块、整屋橙色洗色）。  
5. **禁止** `c02_blacksmith_home` 做成迷你铁匠铺，或 `c04_smith` 做成带床的家。  
6. **禁止**商贾宅 = 杂货店缩小版；农家宅 = 老人宅多几个箱。  
7. **禁止** `barrel_0` 横酒桶出现在酒馆以外当通用桶。  
8. **禁止**只改 `profile_id` / 标题、不改分区与动线。
